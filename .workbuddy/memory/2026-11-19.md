## 采购分析看板（复刻 Power BI「首页」）· 前端落地

**目标**：用 `procurement.db` 的数据 + 照搬 PBIP 的 DAX 口径，在 `/dash` 复刻 PBI 首页的视觉对象、配色与计算逻辑。

### 交付
- `dash_build.py` → `dash_po`(44,987×34) / `dash_calendar` / `dim_category_map`(94 原值→11 类)
- `dashboard_api.py`（Blueprint `/api/dash`）：`/meta`（mtime 缓存）、`/home`、`/agg`
- `templates/dashboard.html`：1280×720 stage + scale 缩放（等价 PBI FitToPage）
- `static/dash/bg-home.jpg`：取自 PBIP 的 Sime 壁纸
- `app.py`：注册蓝图、`TEMPLATES_AUTO_RELOAD`、`GET /dash`（no-store）
- 文档：`前端建设/00_实现路径规划.md` 附录 A（几何/配色/口径/偏差全表）

### 关键经验
1. **PBIP 的 `position` 在 `visual.json` 顶层**，不在 `visual` 里；`isHidden: true` 的组不会渲染（首页 filter panel 就是这种）。
2. **卡片背景色**：`ThemeDataColor ColorId=1` + `transparency 30` 实测 = **纯黑 70%**，不是 dataColors[0] 的深蓝。像素反推：`0.3×(0,58,100) = (0,17,30)` 完全吻合。
3. **PBI 声明字号 ≠ 渲染字号**：卡片 callout 声明 40，实际渲染 ~26（高度约束自动缩）。**以截图像素反推为准**，宽度比高度可靠（AA 会把高度撑大 1–2px）。
4. **截图坐标系校验**：Bridge 截图为 2968×1604，canvas 1280×720 → scale 2.2205，且整体有 (+12.4, +2.1) 偏移，换算时要减掉，否则会误判"居中/左对齐"。
5. **滑出面板必须 `pointer-events:none` + `translateX(calc(100% + 30px))`**：只写 `translateX(102%)` 会留一条 20px 在画布内，挡住右侧 tab 的点击（表现为"点了没反应"）。
6. **零值 YoY 不带箭头**（PBI 三段格式 `"0.0% ▲";0.0% "▼";0.0%`），用 `Math.abs(v)<0.0005` 判零。
7. **meta 慢查询先加索引再谈缓存**：`dash_po` 补 9 个单列索引后 1.4s→0.23s；再叠 mtime 缓存 0.009s；前端与 `/home` 并行 → 首屏 0.5s。

### 已知偏差（记录，勿当 bug 查）
- 背景壁纸比 PBI 小约 4%（同一张图，缩放差异，装饰性）。
- 右侧「筛选器」：PBI 页面里那个组是隐藏的，截图中的竖条是 Desktop 自己的折叠窗格；网页版做成 26px 竖条 + 滑出 7 组多选面板。

## 重做：从"静态封面"改成真正可交互的 HTML 看板

**背景**：附录 A 的做法是照 PBI 截图 1:1 复刻一张 1280×720 的封面（贴壁纸 + 固定坐标卡片），用户反馈「不是只做图像，要做 html 可视化可交互的」——像素再准也只是张图。

### 现在是什么
- `templates/dashboard.html` + `static/dash/dash.css` + `static/dash/dash.js`（零依赖，图表全手写 SVG）
- 5 个视图：概览 / 类别 / 供应商 / 地域 / 明细
- 7 种图表：折线（双系列+十字准线）、横条、帕累托、环形、树图、柱状、迷你趋势
- 交互：交叉筛选（点图形→加 chip→全视图联动）、12 维筛选抽屉（高基数组带搜索）、表头排序、明细搜索、分页、财年切换、深浅主题
- 新增 API：`/trend` `/dist` `/pareto` `/rows` `/supcat`；`/agg` 支持重复 `dim` 做多维分组

### 踩过的坑
1. **`table-layout:fixed` 必须加**：不加时，长文本列（供应商全名）会吃掉宽度，右侧数字列被挤成一条缝，`text-align:right` 看起来像错位。配合 `td{overflow:hidden;text-overflow:ellipsis}` + `title` 才稳。
2. **SVG 文字会溢出形状**：树图/帕累托必须给每块建 `<clipPath>` 并 `clip-path:url(#id)` 引用，否则长中文名直接压到相邻块上（截图一眼可见）。
3. **文字宽度按像素估**：中文 11.2px/字、西文 6.3px/字，`truncate(s, px)` 比按字符数截准得多。
4. **树图列坐标漏累加**：`groups.forEach` 里每个 rect 都有 `x: x`，但忘了循环末尾 `x += w` → 11 列全叠在 x=0（表现为"只画了左边一小条"）。用 `svg > rect` 的 x 值 dump 出来一眼定位。
5. **供应商/门店名是「中文-英文」**：图表里只显示 `-` 前的中文段（`shortName()`），tooltip 保留全名，否则 190px 标签位只够显示 17 个字。
6. **占比分母要用全量**：Top60 供应商表若用自身求和做分母，覆盖率永远 100%。改为并行拉一次 `/home` 取当前筛选下的总额，表头显示「Top 60 · 全量 185 M · 覆盖率 70.3%」。
7. **浅色主题要换色板**：`#99D1E1` 在白卡上对比度约 1.7:1，几乎看不见；浅色下整套系列色换成更深的一版（`PALETTE_LIGHT`），并去掉 KPI 迷你趋势的面积填充（否则像背景污渍）。
8. **`sum` 断言的批量替换要防缩进**：用正则 fallback 替换 Python 代码块时，`new` 的缩进与原位不一致会 `IndentationError`，替换后用 `ast.parse` 校验。
