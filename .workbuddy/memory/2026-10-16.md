## 修复 start-dbadmin.bat 双击报错
- 根因：bat 中 `APP` 写成字面中文路径 `D:/code/采购数据库建设/app.py`；cmd 默认按系统 ANSI 读 .bat，UTF-8 中文乱码 → 找不到 app.py 报错。sh 版（Git Bash 按 UTF-8）不受影响故正常。
- 修复：改用 `%~dp0app.py`（`%dp0` 是 cmd 内部变量，由系统正确提供 bat 目录，不受文件编码影响），彻底规避中文路径字面量；提示语改英文避免乱码；改为前台运行 python（bat 窗口即服务窗口，便于看错误），关闭窗口即停服务。
- 顺手把 `timeout /t 1`（在 WorkBuddy/Git Bash 混合 PATH 下会命中 coreutils 的 timeout 而报 invalid time interval）改为 `ping -n 2 127.0.0.1 >nul` 延时，兼容性更好。
- 验证：用 `cmd //c start-dbadmin.bat` 实测可正常拉起服务（http://localhost:5000 返回 200，netstat 监听 5000）。当前服务 PID 21572 在跑。
