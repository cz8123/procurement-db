### 坑
- **ATTACH 的库不手动 commit 会锁**：UPDATE 关联子查询在 bk 上留读事务，后续 DETACH/再 ATTACH 报 "database bk is locked"；且 Python sqlite3 默认隔离级别下 ALTER TABLE 自动提交但 UPDATE 不会——半途失败会「列加了、数据没回填」。每张表 UPDATE 后立即 `con.commit()`。
- Python sqlite3 legacy 模式：DDL 立即提交，DML 需显式 commit。
